## Core Concept
The Archive is a massive eco-brutalist library that exists between realities. Archivists pull files from countless annexed universes, each identified by an Annex number.

## Annex System
- **A-0001A** — Prime reality (our universe)
- Annex numbers close to A-0001A = similar to our world
- Annex numbers far from A-0001A = increasingly alien
- A-5421D ≈ familiar, M-3204J = unrecognizable

## Key Factions
- **The Pale Lodge** — Order with guiding glyphs (Freedom, Mortality, Quarry, Perpetuity)

## Known Universes (Annexes)
- A-1038B — Repository of stories
- A-4439H — Martian mining operations
- Y-9904P — (connected to A-4439H)
- M-3204J — Far-removed reality
