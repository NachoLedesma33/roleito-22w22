# Terminology

## Core Terms

| Term | Definition |
|------|-----------|
| Archive | The interdimensional library between realities |
| Annex | A universe identified by a code (e.g., A-1038B) |
| Archivist | One who pulls files from annexes |
| Conservator | Patreon supporter tier |
| Curator | Patreon supporter tier |
| Pale Lodge | Mysterious order/faction |
| Guiding Glyphs | Symbols: Freedom, Mortality, Quarry, Perpetuity |
| Compendium | Collection of lore volumes |
| Repository | The Archive's file collection |
| Construct | Unknown entity/concept referenced in stories |

## Annex Code Format
- Letter prefix(s) + dash + numbers + letter suffix
- Distance from A-0001A indicates divergence from prime reality
