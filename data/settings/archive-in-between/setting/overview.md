# Setting Overview

## The Archive
A massive eco-brutalist library existing between realities. Contains files pulled from countless annexed universes.

## The Multiverse
Reality is organized by Annex numbers. Each annex represents a universe variant:
- Prefix letter(s) indicate broad reality cluster
- Number indicates specific variant
- Suffix letter indicates sub-variant

## The Pale Lodge
An order/faction whose symbols appear across multiple annexes. Their seal and guiding glyphs represent core concepts: Freedom, Mortality, Quarry, Perpetuity.

## The Compendium
A collection of documents, stories, and lore organized into volumes. Contains entries about locations, entities, and phenomena across annexes.
